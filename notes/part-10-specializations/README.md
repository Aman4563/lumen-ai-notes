# Part 10 — Domain Specializations

## How to use this part

Study all chapters for breadth, then choose one or two for deep projects. A senior
candidate should connect domain-specific objectives/data biases to general ML
systems rather than applying a generic classifier.

## Common specialization template

```text
domain decision -> outcome/label process -> selection/exposure
-> domain baseline -> model/objective -> offline metric
-> intervention/online metric -> feedback loop/adversary
-> serving/monitoring/governance
```

After the RL chapter, continue with [Part 20: Reinforcement Learning](../part-20-reinforcement-learning/README.md)
for deeper value/policy methods, SAC/TD3, model-based and offline RL, OPE,
imitation, constrained, hierarchical, multi-agent, and language-model RL.
